# مساعد BYD الصوتي الذكي (BYD Arabic Voice Assistant)

تطبيق ومساعد صوتي مخصص لشاشات سيارات **BYD** التي تعمل بنظام **DiLink** (مُختبر ومُصمم خصيصاً لسيارة **BYD Destroyer 05 / دستروير 2025**).

---

## 🌟 الميزات الرئيسية

1. **فهم اللهجة العراقية والعربية الفصحى:**
   - يفهم الكلمات والعبارات اليومية الدارجة: *"فر الشاشة"*، *"نزل الجامة"*، *"شعل المكيف وسوي الحرارة 22"*، *"علي الصوت"*.
   - يفهم الأوامر بالفصحى الرسمية: *"أدر الشاشة"*, *"افتح النوافذ"*, *"أوقف التكييف"*.
2. **ردود صوتية فصيحة مشكولة بالكامل (100%):**
   - لتفادي نطق الحروف الخاطئ من محركات الصوت (TTS)، تُنتج الردود بحركات إعرابية تامة:
     - «حَاضِرٌ، تَمَّ تَدْوِيرُ الشَّاشَةِ.»
     - «تَمَّ تَشْغِيلُ التَّكْيِيفِ، وَضَبْطُ الحَرَارَةِ عَلَى اثْنَتَيْنِ وَعِشْرِينَ دَرَجَةً.»
     - «تَمَّ فَتْحُ النَّوَافِذِ.»
3. **جسر التحكم بسيارة BYD (DiLink Vehicle Bridge):**
   - مستوحى من المشاريع مفتوحة المصدر (`wheregoes/byd-apps` و `AndyShaman/BYDMate`).
   - يتخاطب مع خدمات الشاشة الداخلية عبر تقنية الـ Reflection (`ServiceManager` -> `byd_auto_air`, `byd_auto_window`) وبث النظام الخاص بتدوير الشاشة (`com.byd.intent.action.ROTATION_SCREEN`).
   - دعم التراجع الآمن (Safe Fallback) لمنع أي تعليق في النظام.
4. **زر عائم خفيف فوق الشاشة والخرائط (Floating Mic Button):**
   - خدمة مستمرة (Foreground Service) لا يغلقها النظام.
   - زر دائري أنيق يظهر فوق خرائط Google وتطبيقات الموسيقى يمكنك سحبه لأي زاوية بلمسة واحدة.
   - خفض صوت الموسيقى تلقائياً (Audio Ducking) أثناء الاستماع.
5. **معمارية معيارية قابلة للترقية:**
   - واجهة `ArabicIntentResolver` مفصولة تماماً، مما يتيح ربط نموذج ذكاء اصطناعي (LLM مثل Gemini / ChatGPT) في المستقبل بكل سلاسة.

## 🛠️ كيفية تجربة وتشغيل المحاكي (CLI Simulator)

يمكنك تجربة منطق التعرف الصوتي والأوامر فوراً عبر Node.js:
```bash
node test_simulator.js
```

أو تشغيل اختبارات جافا الشاملة:
```bash
javac -encoding UTF-8 -d bin app/src/main/java/com/byd/assistant/**/*.java app/src/test/java/com/byd/assistant/**/*.java
java "-Dfile.encoding=UTF-8" -cp bin com.byd.assistant.AssistantSimulationSuite
```

## 📲 التثبيت على شاشة سيارة BYD DiLink

1. **بناء ملف الـ APK:**
   - افتح المشروع في **Android Studio**.
   - اختر `Build > Build Bundle(s) / APK(s) > Build APK(s)`.
2. **التثبيت عبر فلاش ميموري (USB):**
   - انسخ ملف `app-release.apk` إلى فلاش ميموري (مفرمتة بنظام FAT32).
   - ضع الملف داخل مجلد باسم `Third Party Apps` (أو مباشرة في الجذر حسب إصدار DiLink).
   - وصّل الفلاش في منفذ USB الخاص بنقل البيانات في سيارة دستروير.
   - افتح تطبيق إدارة الملفات في الشاشة واضغط تثبيت.
3. **التثبيت عبر ADB اللاسلكي (Wireless ADB):**
   - ادخل إلى إعدادات النظام في شاشة السيارة، وفعّل خيارات المطور (Developer Options).
   - اربط الحاسوب والشاشة على نفس شبكة الواي فاي وثبت التطبيق:
   ```bash
   adb connect <IP_CAR_SCREEN>:5555
   adb install app-release.apk
   ```
4. **تفعيل الصلاحيات عند أول تشغيل:**
   - عند فتح التطبيق، امنح إذن **الظهور فوق التطبيقات الأخرى** (Display over other apps).
   - امنح إذن **تسجيل الصوت / الميكروفون**.
   - اضغط **تشغيل المساعد الصوتي** وسيظهر الزر العائم فوراً!
